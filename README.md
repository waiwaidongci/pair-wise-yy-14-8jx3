# hxyfront-62013 白蚁熏蒸隔离与复位放行台（古建木结构榫卯）

在原「木结构榫卯构件测绘」页面基础上扩展为**白蚁熏蒸隔离与复位放行台**：保留构件测绘
（建筑/编号/木种/榫卯/截面尺寸/病害/换件/修缮建议），新增施药登记、隔离复检、复位放行、
批次台账与构件关系图。

## 业务规则

1. **同一仓罩仅接一批**：仓罩处理中（熏蒸未复位）重复登记时沿用首批，不新开批次、不重复施药；
   被整批拒绝或已作废的批次不占用仓罩；放行复位后仓罩自动释放，可接新批。
2. **施药登记**：登记药剂批次、浓度、仓压与施药人；**药剂过期或仓压不足（<250Pa）整批拒绝**，
   拒绝批仍入台账留痕但只读、不占仓罩。
3. **复检放行**：熏蒸后由**非施药人**执行复检，两次复检节点间隔**不少于 24 小时**；
   两次均满足**蛀屑无新增**且残留浓度回落（≤5ppm）方可复位放行。
   发现新增蛀屑或末次浓度未回落，批次作废、须重新熏蒸。
4. **关键变更失效**：处理期间（熏蒸中或放行后）修改构件**截面尺寸 / 病害 / 换件**，
   原放行失效、批次作废重算，**旧批只读封存**，须重新登记熏蒸；木种、修缮建议等非关键字段不影响。
5. **三处一致**：构件清单、隔离队列、关系图均从同一份批次账派生；数据持久化到
   `localStorage`，页面刷新后状态一致。

## 代码分层

| 文件 | 职责 |
| --- | --- |
| `src/fumigation/rules.ts` | 判定层：仓罩占用、过期/仓压、复检人/24h 间隔/蛀屑/浓度、放行、关键变更、状态相位（纯函数） |
| `src/fumigation/ledger.ts` | 批次账：台账状态机、登记/拒批留痕、复检、放行、作废、构件变更、localStorage 持久化、演示账 |
| `src/fumigation/station.tsx` | 界面状态：Context 全局台账与时钟、操作动作、视图焦点与提示、统一派生选择器 |
| `src/views/ComponentList.tsx` | 构件清单：榫卯类型/状态筛选、测绘字段维护、关键变更警示 |
| `src/views/RegisterView.tsx` | 施药登记：选仓罩/构件、药剂批次/浓度/仓压/施药人、提交前判定 |
| `src/views/QueueView.tsx` | 隔离队列：24 小时倒计时、两次复检、复位放行 |
| `src/views/LedgerView.tsx` | 批次台账：留痕检索、旧批只读、放行快照与现况对比 |
| `src/views/GraphView.tsx` | 关系图：建筑 → 构件 → 仓罩/批次（SVG） |

## 技术栈

React 19 + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62013

页面右上角「重置为演示台账」可清除本地数据并恢复演示批次（含熏蒸中、待复检、
整批拒绝、放行后换件失效等各状态样例）。
