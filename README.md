# hxyfront-62013 白蚁熏蒸隔离与复位放行台

源提示词编号：8

在古建筑木结构榫卯构件测绘台账上扩展的白蚁熏蒸作业台：测绘人员维护构件清单（建筑名称、构件编号、木材种类、榫卯类型、截面尺寸、病害位置、变形情况、修缮建议），熏蒸班组在仓罩内成批隔离处理构件，复检合格后复位放行。

## 业务规则

- **同一仓罩仅接一批**：仓罩下已有入仓批次时，重复登记直接沿用首次批次；整批拒绝的批次未入仓，不占仓罩。
- **登记**：每批登记药剂批次、施药浓度、仓压和施药人；药剂过期或仓压不足（低于 30Pa）时整批拒绝，拒绝批只读。
- **复检**：熏蒸后由非施药人复检两次，两次间隔须满二十四小时（页面提供“推进 24 小时”演示时钟）。
- **放行**：两次复检蛀屑均无新增，且残留浓度回落至 0.5g/m³ 以下，才可复位放行。
- **失效重算**：处理期间（含已放行）修改构件尺寸、病害或换件，涉及批次原放行失效、旧批只读，构件回到“待重算”，需另开仓罩登记新批。
- **一致性**：构件清单、隔离队列、关系图均由同一状态派生，并持久化到 localStorage，刷新后三处一致。

## 代码结构（判定 / 批次账 / 界面状态分离）

- `src/business/fumigationRules.ts` —— **判定**：登记、复检、放行、失效的纯判定逻辑与阈值常量。
- `src/business/batchLedger.ts` —— **批次账**：批次与流水的唯一写入口（只追加不篡改），以及清单 / 隔离队列 / 关系图的派生口径。
- `src/business/useStationState.ts` —— **界面状态**：reducer + 持久化，所有视图同源派生。
- `src/data/seed.ts` —— 演示种子数据（含一笔已放行历史批与一笔在熏批）。
